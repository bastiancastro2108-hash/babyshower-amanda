# Baby Shower de Amanda

Invitación, confirmación de asistencia y lista de regalos para el baby shower de Amanda (7 de noviembre de 2026).

- `public/` — la página que ven los invitados.
- `netlify/functions/api.mjs` — guarda reservas de regalos y confirmaciones (Netlify Blobs).
- Panel de organizador: `/#organizar`. La clave se cambia con la variable de entorno `ADMIN_PIN` en Netlify.
